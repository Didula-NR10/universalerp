# Cloud infrastructure

The ERP is intended to use Supabase PostgreSQL and Supabase Auth. Deploy the Spring Boot API and built React frontend on cloud hosts, then configure the environment variables in [setup](../docs/development/setup.md). No local PostgreSQL container is part of this repository.

The deployment templates have not been run in this workspace. Production still requires database grants, backups, secret management, integration testing, and a security review.
