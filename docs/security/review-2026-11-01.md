# Security review — 2026-11-01

Scope: repository inspection, automated tests and a local HTTP check against the approved Supabase PostgreSQL test project. This is not a production security signoff.

| Area | Verified control | Remaining work |
| --- | --- | --- |
| Authentication | ERP-owned BCrypt credentials; locally signed JWTs; signature, issuer, audience, expiry and session-version checks; login and password-change flow tested on PostgreSQL; live HTTP login succeeded | External penetration test, recovery procedure and gateway rate limiting |
| Authorization | Active profile, role and branch checks; temporary-password accounts cannot use business permissions; self-role and self-password-reset guards | Cross-branch API tests and review of every resource ownership path |
| Account abuse | Five failed attempts lock a known account for 15 minutes; login errors do not reveal whether an email exists | Per-IP limits at the gateway; alerting for failed attempts |
| Token handling | Eight-hour bearer token in browser `sessionStorage`; logout and password change revoke sessions by version | Review browser XSS defenses and consider shorter token lifetime/refresh flow before production |
| Input and SQL | Jakarta Validation and bound JDBC parameters | Fuzz invalid payloads and review dynamic queries |
| CORS and CSRF | Explicit frontend origin; Authorization header instead of ambient cookies | Browser preflight and HTTPS deployment checks |
| Secrets | Random 32-byte JWT signing key in ignored local `.env`; no Supabase Auth key in frontend | Move to managed secret store for deployment; rotate database password shared earlier in chat |
| Audit and integrity | Business mutations and successful auth actions append audit records; stock and refunds use idempotency | Failed-login audit/monitoring, immutable table grants, concurrency and rollback tests |
| Dependencies | Frontend npm audit reported zero vulnerabilities | Backend and container scans |

Supabase PostgreSQL schema version 13 is applied to the approved test project. No production deployment has been performed.
